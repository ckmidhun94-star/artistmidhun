# Midhun C K — 3D Artist Portfolio

A single-page portfolio built with React, TypeScript, and Vite. Run `npm ci` to install dependencies, `npm run dev` to start the local preview, and `npm run build` to create the deployable `dist/` folder. Static images and videos are stored under `public/`.

See [LICENSE](./LICENSE) and [NOTICE](./NOTICE) for licensing information.

## Deploy to GitHub Pages

Pushing to `main` runs `.github/workflows/deploy.yml` to build and deploy `dist/`. In the repository settings, set Pages' build and deployment source to **GitHub Actions**. The custom domain is `artistmidhun.com` (`public/CNAME`); configure the domain's DNS for GitHub Pages and wait for DNS verification and HTTPS provisioning.
